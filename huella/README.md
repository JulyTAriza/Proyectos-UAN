# Huella · Prototipo navegable y sistema de diseño

Proyecto semestral de **Diseño de Interfaces de Usuario** (Universidad Antonio Nariño, 2026).
Autora: July Tatiana Ariza Peña.

Huella es una aplicación de bienestar emocional a través de encuentros con animales de refugio.
Esta carpeta contiene los resultados de las guías 5 y 6:

El prototipo está hecho en HTML, CSS y JavaScript, sin backend: los animales, refugios y cupos son datos ficticios
y las respuestas se simulan en el navegador. Para verlo localmente basta con abrir `index.html` desde un servidor
estático (por ejemplo `python3 -m http.server`).
